薪資單產生器 Payslip Generator

把 Excel 薪資單轉成每位員工一份的加密 PDF，並在您自己的 Gmail 建立草稿。

隱私權政策 Privacy Policy 聯絡開發者

這是什麼

薪資單產生器是一個在 Windows 電腦上執行的桌面工具，協助人事或會計人員處理每月的薪資單：

  • 讀取 Excel 薪資單，自動找出每一位員工的薪資單，由 Microsoft Excel 輸出成 PDF。
  • PDF 可加密，開啟密碼為員工的身分證字號。
  • 在使用者自己登入的 Gmail 建立草稿：每位員工一封（附本人 PDF），另可建立一封給客戶窗口的草稿。
  • 只建立草稿，不會自動寄出；寄出前由使用者在 Gmail 確認。

使用 Google 帳戶的方式

本工具使用 Gmail API，只要求一個權限：https://www.googleapis.com/auth/gmail.compose（管理草稿及寄送電子郵件），用途僅限於在使用者自己的信箱建立草稿。本工具不會讀取、搜尋或刪除任何郵件。

薪資資料與 PDF 都在使用者的電腦上處理，不會傳送到開發者的伺服器。詳細內容請見隱私權政策。

系統需求

  • Windows 10 / 11
  • Microsoft Excel（桌面版）
  • Google Chrome 或 Microsoft Edge
