1. 適用範圍

本政策說明「薪資單產生器」（以下稱「本工具」）在使用者以 Google 帳戶登入後，如何存取、使用、儲存與分享資料。本工具是在使用者電腦上執行的桌面程式，開發者沒有架設任何接收使用者資料的伺服器。

2. 存取的 Google 使用者資料

本工具只要求一個 Google 權限：

  • https://www.googleapis.com/auth/gmail.compose（管理草稿及寄送電子郵件）

透過這個權限，本工具只會做兩件事：

  • 建立草稿：依使用者在本工具中設定的收件者、主旨、內文與附件（薪資單 PDF 或 ZIP），在使用者自己的 Gmail 建立草稿。
  • 讀取帳戶的 Email 位址：用來在畫面上顯示目前登入的帳戶，並作為草稿的寄件者。

本工具不會讀取、搜尋、修改或刪除使用者的任何郵件，也不會自動寄出郵件；草稿是否寄出，由使用者自行在 Gmail 決定。

3. 資料的使用

從 Google API 取得的資料只用於上述功能，也就是在使用者自己的信箱建立薪資單草稿。不會用於廣告、不會出售，也不會用來訓練人工智慧或機器學習模型。

4. 資料的儲存

  • 薪資資料：使用者選擇的 Excel 檔、產生的 PDF 與員工對照表（含 Email 與身分證字號），都只在使用者的電腦上處理。除了以草稿附件的形式透過 Google API 存入使用者自己的 Gmail 之外，不會傳送到其他地方。
  • 登入資訊：Google 核發的 OAuth 授權憑證只儲存在使用者電腦的 %APPDATA%\PayslipGenerator\ 資料夾中，開發者無法取得。
  • 本工具執行時產生的暫存檔，會在程式結束時刪除。

5. 資料的分享

本工具不會將任何 Google 使用者資料分享、出售或移轉給開發者或任何第三方。資料只在使用者的電腦與 Google 之間傳輸（用於建立草稿），傳輸皆使用 HTTPS 加密連線。

6. 遵守 Google API 服務使用者資料政策

薪資單產生器對從 Google API 取得之資訊的使用，以及將這些資訊傳輸至任何其他應用程式，皆遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定。

Payslip Generator's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. 撤銷授權與刪除資料

  • 在本工具的「⚙ 寄信設定」按「登出」，會撤銷授權並刪除電腦上的登入資訊。
  • 也可以隨時到 Google 帳戶 → 第三方應用程式與服務 移除「薪資單產生器」的存取權。
  • 刪除電腦上的 %APPDATA%\PayslipGenerator\ 資料夾，即可移除本工具留在電腦上的所有設定與登入資訊。
  • 已建立的 Gmail 草稿屬於使用者的信箱，可在 Gmail 中自行刪除。

8. 政策更新與聯絡方式

本政策如有變更，會更新本頁面並修改上方的「最後更新」日期。對本政策或資料處理方式有任何問題，請聯絡開發者 win861122：win861122@gmail.com

Summary (English)

Payslip Generator is a Windows desktop tool. It requests only the gmail.compose scope, used solely to create drafts (payslip PDFs as attachments) in the signed-in user's own Gmail account and to read the account's email address for display. It never reads, searches, modifies or deletes email, and never sends email automatically. Payroll data is processed locally on the user's computer; OAuth tokens are stored only on that computer. No Google user data is shared with the developer or any third party, sold, used for advertising, or used to train AI/ML models. Users can revoke access at any time at myaccount.google.com/permissions. Contact: win861122@gmail.com.
